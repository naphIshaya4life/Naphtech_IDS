
🛡️ Naphtech IDS

Version: 2.0.0 Stable

A modular Intrusion Detection System (IDS) developed in Python for educational and cybersecurity training purposes. Naphtech IDS monitors simulated network traffic, detects suspicious activity based on configurable thresholds, logs alerts, and provides a simple command-line dashboard for monitoring system status.

---

✨ Features

- Simulated network traffic monitoring
- Suspicious activity detection
- Configurable detection threshold
- Alert logging
- Alert history viewer
- Alert management
- Real-time statistics
- Threat level indicator (LOW, MEDIUM, HIGH, CRITICAL)
- Visual threat meter
- System uptime tracking
- Interactive command-line menu
- Modular project structure

🚀 Installation

Clone the repository:

git clone https://github.com/naphIshaya4life/Naphtech_IDS.git

Enter the project directory:

cd Naphtech_IDS

Install dependencies:

pip install -r requirements.txt

Run the application:

python ids.py
