

Changelog

All notable changes to Naphtech IDS will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

---

[2.0.0] - 2026-08-05

Added

- Interactive command-line menu.
- Real-time network traffic simulation.
- Configurable detection threshold using "config.json".
- Alert Center for viewing and managing alerts.
- Dashboard displaying system statistics.
- Threat level classification (LOW, MEDIUM, HIGH, CRITICAL).
- Visual threat meter with traffic-light indicators.
- System uptime tracking.
- Modular project architecture.
- Logging system for events and alerts.
- Project documentation structure ("README", "ROADMAP", "LICENSE").
- Dedicated folders for assets, documentation, backups, reports, and screenshots.

Improved

- Cleaner project structure.
- Better code organization and readability.
- Improved error handling.
- Enhanced logging messages.
- More consistent comments and documentation.

Fixed

- Resolved statistics-related issues.
- Fixed method and class integration problems.
- Corrected indentation and formatting issues.
- Fixed multiple syntax and runtime errors encountered during development.

---

[1.0.0] - 2026-07-20

Added

- Initial release of Naphtech IDS.
- Basic traffic simulation.
- Packet counting.
- Suspicious activity detection using a configurable threshold.
- Alert logging to file.
- Console-based monitoring output.
